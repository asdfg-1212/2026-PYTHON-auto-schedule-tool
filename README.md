# 智能日程安排工具 📅

> 一个基于Python的自动化任务调度系统，支持deadline分段调度、任务拆分、前瞻性时间预留等高级功能。


## 📋 项目简介

**智能日程安排工具**是一个命令行交互式应用，可根据任务的**重要性、截止时间、预计用时**等属性，自动生成单日日程安排。系统支持设置课程表和默认作息时间（起床、三餐、睡觉），调度算法会自动避让这些固定时段。此外还提供**任务智能拆分**、**历史日程保留**、**临时作息调整**等功能。

**核心特性**：
- **智能调度**：按deadline分段调度 + 前瞻性时间预留
- **课表管理**：支持导入每周固定课程
- **作息时间**：每日作息支持默认与调整相结合
- **数据持久**：历史日程自动保存，支持跨日查看与设置
- **可视展示**：清晰的时间线 + 重要性 + 备注
- **任务拆分**：可拆分的长任务支持跨时段排布

## 🎯 高级功能

### 1. 任务拆分
- 自动将任务拆分为多个部分
- 显示"part 1"、"part 2"等
- 优先继续已开始的任务，减少碎片化

**示例**：<br>
task: 完成python大作业，预计用时180分钟，重要性5，无时间约束，可拆分<br>
结合当日固定日程，系统生成如下安排：
```
09:00 - 09:10  [任务(重要性:5)] 完成python大作业 - Part 1
......
13:40 - 14:00  [任务(重要性:5)] 完成python大作业 - Part 2
......
17:00 - 18:00  [任务(重要性:5)] 完成python大作业 - Part 3
......
18:30 - 20:00  [任务(重要性:5)] 完成python大作业 - Part 4
```

### 2. deadline智能调度 && 前瞻性时间预留
- 计算每个任务的"最晚开始时间"
- 优先安排接近最晚开始时间的任务
- 提示无法完成的任务
- 在某时间之后无可用时间时，强制在前面安排任务，避免错过deadline

**示例**：<br>
task: 复习英语单词 预计用时60分钟，重要性3，deadline=14:20，不可拆分<br>
结合当日固定日程和任务重要性，系统识别到在10:10后无足够连续时间完成任务，计算出最晚开始时间为09:10，做出如下安排：
```
09:10 - 10:10  [任务(重要性:3)] 复习英语单词  💡 不要边复习边听陈奕迅
```
task: sleep 预计用时500分钟，重要性1，deadline=23:40，不可拆分<br>
系统计算出最晚开始时间为18:00，但18:00后仅剩220，无法完成任务，做出如下提示：
```
[Scheduler] 提示: 以下任务无法完全安排:
- sleep (部分完成，还剩 280/500 分钟)
```

## 📊 调度算法说明

调度核心：**deadline分段 + 不可拆分优先 + 前瞻性时间预留**

1. **阶段一**：优先处理约束严格的任务
   - **1.1** 固定起始时间 + 不可拆分 → 直接锁定，若冲突则任务失败
   - **1.2** 固定起始时间 + 可拆分 → 从起始时间开始安排第一部分（锁定开始时间）
   - **1.3** 有deadline + 不可拆分 → 从后往前找连续可行时段（find_latest_continuous_slot）
   - **1.4** 无约束 + 不可拆分 → 按重要性排序

2. **阶段二**：按deadline分段
   - 将一天分为多个时间段，每段以某个deadline结束，不考虑已有的任务和固定日程
   - 每个segment内，优先处理对应segment的任务，确保在其截止前完成

3. **阶段三**：贪心填充 + 前瞻性预留
   - 在当前 segment 内的某个时间点 current_time，算法会：
     - 区分三类任务：
       - must_complete：deadline 就是本段右端点，且还有剩余时长
       - need_space：只依赖未来空闲时间一定无法做完的任务
       - available：其他普通任务
     - 预留时间：
       - 计算本段剩余时间
       - 优先为 must_complete 和 need_space 任务预留出足额时间
       - 剩余的时间可供 available 任务使用
     - 选择下一个要执行的任务：
       - 优先处理 must_complete、need_space 任务
       - 再次继续已经开始过的任务（减少碎片化）
       - 最后重要性最高的 available 任务
       - 每次切出一段不超过任务剩余时长、且不破坏预留时间的连续区间分配

## ⚠️ 常见问题
### Q1: 配置文件损坏怎么办？

**解决方法**：删除配置文件，重新运行程序
```bash
rm config/user_config.json
python main.py  # 会重新进入配置向导
```

### Q2: 中文显示乱码（Windows）

**解决方法**：设置终端编码为UTF-8
```bash
chcp 65001
python main.py
```

### Q3: 系统如何处理错误输入？

系统内置了完善的输入验证机制，会友好地提示错误并要求重新输入：

**场景1：任务用时输入错误**
```
预计用时（分钟）: abc
❌ 请输入有效的数字！
预计用时（分钟）: -10
❌ 时间必须大于0！
预计用时（分钟）: 120
[继续]
```

**场景2：重要性超出范围**
```
重要程度 (1-5, 5为最重要): 10
❌ 请输入1-5之间的数字！
重要程度 (1-5, 5为最重要): 5
[继续]
```

**场景3：时间格式错误**
```
起始时间 (格式: HH:MM, 可选, 回车跳过): 25:00
⚠️ 起始时间格式错误，已忽略。

截止时间 (格式: HH:MM, 可选, 回车跳过): 18点
⚠️ 截止时间格式错误，已忽略。
```

**场景4：作息时间冲突**
